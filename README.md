# 🏁 竞速答题（视频题目 · 扫码抢答）

一个局域网内的多人实时竞速答题系统：主持人用电脑放大屏，参赛者用手机扫码加入抢答。

## 功能对照
1. ✅ **可编辑题目/答案**：网页编辑页，每题「先播放视频 → 主持人点击后显示选项」。
2. ✅ **后台操控进度**：主持人大屏上的按钮控制「显示选项 / 公布答案 / 下一题」。
3. ✅ **扫码加入**：手机扫二维码进入，输入昵称、选头像；默认头像为随机卡通动物。
4. ✅ **答题反馈**：每题结束显示答对/答错，并播放正确答案对应的视频片段。
5. ✅ **实时排名**：按「答对 + 答题速度」计分，每题后显示当前排名。
6. ✅ **结果页**：最终排名 + 每道题各选项对应的视频片段回顾。

## 快速开始

需要先安装 [Node.js](https://nodejs.org/)（LTS 版即可）。

```bash
cd quiz-race
npm install     # 首次运行，安装依赖（需要联网一次）
npm start       # 启动服务器
```

> 依赖已经装好了，直接 `npm start` 即可。
> 如果以后重装依赖时报 `SELF_SIGNED_CERT_IN_CHAIN`（公司网络代理常见），改用：
> `npm install --strict-ssl=false`

启动后终端会显示三个地址：

- **主持人大屏**：http://localhost:3000/host
- **题目编辑**：http://localhost:3000/editor
- **玩家加入**：http://<你的电脑局域网IP>:3000/player （手机扫大屏二维码即可）

> ⚠️ 手机必须和电脑连同一个 WiFi / 局域网。

## 两种启动模式

| 双击文件 | 适用场景 | 说明 |
|----------|----------|------|
| **启动答题.bat**（或 run.bat） | 手机和电脑**同一 WiFi/局域网** | 最简单最稳定，二维码指向电脑局域网地址 |
| **启动答题-手机流量版.bat** | 手机用**流量/4G/5G**，或不在同一网络 | 自动开 Cloudflare 公网隧道，二维码指向 https 公网地址，手机任意网络可扫码加入 |

> 手机流量版需要**电脑能访问外网**。已内置 `cloudflared.exe`，无需再下载。
> 若公司防火墙拦截了 Cloudflare，黑窗口会提示失败——可改用手机热点给电脑联网，或改回局域网模式。
> 隧道地址每次启动都会变，主持人大屏上的二维码会自动刷新成最新公网地址（启动后等几秒）。

## 使用流程

1. 打开 **编辑页** 准备题目（可填在线视频 URL，或把视频放进 `videos/` 文件夹 / 点上传）。
2. 打开 **主持人大屏**，投影到大屏幕，展示二维码。
3. 参赛者手机扫码 → 输入昵称、选头像 → 进入。
4. 主持人点「开始比赛」→ 每题：播放视频 → 「显示选项」→ 大家抢答 → 「公布答案」（播正确片段+排名）→ 「下一题」。
5. 最后一题公布后点「查看最终结果」，展示领奖台、完整排名和所有题目视频片段。

## 界面风格
- 大屏与手机采用「盛世天下」宫廷风：大屏用 **背景1（朱红莲台）**，手机用 **背景2（青绿描金）**，配金描楷体。
- 背景图放在 `public/assets/bg1.jpg`、`bg2.jpg`，可自行替换同名文件更换背景。

## 头像库（本地图片）
- 把头像图片放进 **avatars/** 文件夹（支持 png/jpg/jpeg/gif/svg/webp），参赛者加入时即可从中挑选。
- 已预置 9 张宫廷人物头像（来自素材「头像crop」），可删除或替换成自己的。
- 文件夹为空时，手机端自动回退到「随机卡通动物 emoji」。
- 参赛者**仅在大厅（开考前）**可点头像旁的「✏️ 修改」更换昵称/头像；开考后锁定。

## 答题限时
- 每题限时取自题目的 **答题时长(秒)**（编辑页可改，示例第 1 题为 10 秒）。
- 大屏和手机都会显示倒计时；**倒计时归零自动结束该题**（也可由主持人提前点「公布答案」）。
- 计分：答错/未答 = 0 分；答对 = `500 + 500 × (1 − 用时/时长)`，越快分越高。

## 题目数据
题目保存在 `data/questions.json`，编辑页会自动读写。字段说明：

```jsonc
{
  "questions": [{
    "prompt": "题目文字",
    "questionVideo": "先播放的视频 (URL 或 /videos/xxx.mp4)",
    "timeLimit": 20,              // 答题秒数，用于速度计分
    "correctIndex": 1,           // 正确选项下标(从0开始)
    "options": [
      { "text": "选项文字", "video": "该答案对应的视频片段" }
    ]
  }]
}
```

## 计分规则
答对得分 = `500 + 500 × (1 − 用时/时长)`（越快越高，范围 500~1000）；答错/未答 0 分。
排名先按总分降序，再按总用时升序。

## 端口
默认 3000，可用环境变量修改：`PORT=8080 npm start`（Windows: `set PORT=8080 && npm start`）。
